# Sistema de Cadastro de Clientes

Sistema desenvolvido em Python para cadastro e gerenciamento de informações de clientes.

## Sobre o projeto

Este projeto está sendo desenvolvido como forma de praticar conceitos fundamentais de programação em Python.

A proposta é criar um sistema capaz de cadastrar, consultar, alterar, excluir e listar clientes cadastrados.

Atualmente, o projeto possui a estrutura inicial do sistema e a funcionalidade de cadastro de clientes está em desenvolvimento.

## Funcionalidades

### Em desenvolvimento

- [x] Cadastro inicial de cliente
- [ ] Consulta de cliente por CPF
- [ ] Alteração dos dados de um cliente
- [ ] Exclusão de cliente
- [ ] Listagem de todos os clientes cadastrados
- [ ] Armazenamento de múltiplos clientes
- [ ] Validação dos dados cadastrados

## Dados do cliente

O sistema foi estruturado para trabalhar com as seguintes informações:

- Nome
- CPF
- Data de nascimento
- Endereço
- Número de celular
- E-mail
